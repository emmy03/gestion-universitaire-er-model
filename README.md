# Projet - Gestion d'une plateforme universitaire (Modélisation ER)

Ce projet consiste à concevoir un modèle Entité-Relation (ER) pour gérer les données d'une plateforme universitaire. Il couvre les entités principales comme les étudiants, enseignants, cours, examens, inscriptions et notes, et définit leurs relations pour construire une base de données relationnelle.

## Objectifs

- Identifier les entités principales : Étudiant, Enseignant, Cours, Examen, Inscription, Note.
- Définir les relations et les cardinalités entre ces entités (1 à N, M à N).
- Spécifier les attributs et les clés primaires/étrangères.
- Créer un diagramme ER pour illustrer la structure des données.

## Méthodologie

1. **Identification des entités** : Définir les entités et leurs attributs.
2. **Relations et cardinalités** : Identifier les relations entre les entités et définir les cardinalités.
3. **Diagramme ER** : Créer un diagramme ER clair.
4. **Rapport d’analyse** : Documenter le processus de modélisation et les choix réalisés.

## Technologies

- **Modélisation ER** : Utilisation de draw.io, Lucidchart ou Microsoft Visio.
- **SGBD** : PostgreSQL pour la gestion de la base de données relationnelle.
